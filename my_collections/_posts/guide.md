# Github Guide
## How to edit existing pages on the website

Click on the page you want to edit within the github repository. Published blog posts can be found here: [https://github.com/35percent/35percent.github.io/tree/main/my_collections/_posts](https://github.com/35percent/35percent.github.io/tree/main/my_collections/_posts) and draft blog posts can be found here: [https://github.com/35percent/35percent.github.io/tree/main/my_collections/_drafts](https://github.com/35percent/35percent.github.io/tree/main/my_collections/_drafts).

Next, click on the pencil icon at the top right of the page to enter editing mode:<img src="/assets/images/github-edit.png" alt="github edit image">

![image of editing at github](/assets/images/githubedit.png)

## How to create a new blog post

To create a new post click on the 'add file'/'create file' button on the top right of the '_posts' page:

![create](/assets/images/create.png)

Note that for a blog post to be published it must be placed in the '_posts' folder and the file must be named according to the following conventions:

![create post 1](/assets/images/createpost1.png)

The blog post must also include the following two lines of 'front matter' heading text at the top of the file:

![create post 2](/assets/images/createpost2.png)

## Editing mode

Once in editing mode you can edit the text directly or add images and pdf documents, either by dragging and dropping them into the page or copying and pasting them in. You can also use the 'add image' button at the bottom of the page.

This text editor differs from most word processing environments in that it uses 'Markdown' - a lightweight markup language for creating formatted text using a plain-text editor. You can read a short guide on how to use Markdown tags [here](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

This guide shows for example, how to insert hyperlinks:

![Github Hyperlinks](/assets/images/githubhyperlinks.png)

When you have finished editing, you can review what the page will look like by clicking on the 'Preview' button. If you are happy with the changes, click the green 'Commit Changes' button: <img src="/assets/images/github-commit-changes.png" alt="github button">
